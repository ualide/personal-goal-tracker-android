# Personal Goal Tracker (Android)

## 📱 Overview
Personal Goal Tracker is an Android mobile application designed to help users manage, organize, and achieve their personal goals efficiently. The application allows users to create, track, and update their objectives while building good habits over time.

This project was developed as a Final Year Project for a Bachelor's degree in Mathematics and Computer Science (Software Engineering) at Ibn Zohr University.

---

## 🎯 Features
- User authentication (Sign up / Login / Logout)
- Password recovery via email
- Create, update, and delete personal goals
- Organize goals into themes and sub-themes
- Track progress using criteria and status updates
- Set reminders to stay motivated
- Fully responsive and user-friendly interface

---

## 🛠️ Technologies Used
- Kotlin (Android Development)
- Android Studio (IDE)
- Firebase (Authentication & Database)
- UML (System design and modeling)
